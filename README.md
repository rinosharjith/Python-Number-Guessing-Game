# 🎮 Python Number Guessing Game

A simple, beginner-friendly Number Guessing Game built with Python. The player tries to guess a predefined secret number between 1 and 20 within five attempts.

## ✨ Features

- Predefined secret number (`13`)
- Number range from 1 to 20
- Maximum of 5 guessing attempts
- Tracks the number of attempts
- Displays a success message when the correct number is guessed
- Simple, interactive command-line gameplay

## 🛠️ Built With

- Python 3
- Variables
- `while` loops
- Conditional statements (`if`)
- User input (`input()`)
- `break`

## ▶️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rinosharjith/Python-Number-Guessing-Game.git
```

### 2. Open the project folder

```bash
cd Python-Number-Guessing-Game
```

### 3. Run the program

```bash
python number_guessing_game.py
```

## 🎯 How to Play

1. Run the Python program.
2. Enter a number between 1 and 20 when prompted.
3. You have up to 5 attempts to guess the secret number.
4. Guess the correct number to win!

> **Tip:** The secret number is currently set to `13` in the source code.
